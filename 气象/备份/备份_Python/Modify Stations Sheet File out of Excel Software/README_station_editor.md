# 气象站数据编辑器

这是一个仅在本机运行的浏览器编辑页，可修改工作簿中的 `min`、`max`、`avg` 三列，并在指定 ID 后插入新站点行。

## 启动

1. 确保 Python 和 `openpyxl` 已安装。若缺少 `openpyxl`，在此文件夹打开命令行并运行 `python -m pip install -r requirements.txt`。
2. 双击 `start_station_editor.bat`。浏览器会打开 `http://127.0.0.1:8765`。
3. 保持启动窗口运行；完成后按 `Ctrl+C` 关闭服务。

页面顶部的“工作簿路径”输入框可修改文件位置；点击“载入此文件”后，编辑器会先验证文件。最近一次成功载入的路径会保存在 `station_editor_config.json`，下次启动继续使用。首次启动默认使用 `station_editor.py` 中的 `DEFAULT_WORKBOOK_PATH`。

## 编辑

- 表格按工作簿中的原始行序显示（即 `id` 顺序）。国家读取 `country` 列，省份读取 `level1` 列；搜索和筛选只改变网页显示，不会改变工作簿顺序。
- 在某一站点的数据单元格中粘贴制表符 / 换行分隔的数据块，行为与 Excel 相同，从当前单元格开始向右、向下填充。粘贴范围超出 `avg` 时，右侧多余列会忽略；粘贴后焦点停留在最后一个受影响的数据格。
- 修改后该站点整行显示红框。点击该行的“保存此站”只保存这一个站点；“保存所有未保存站点”会逐行保存。
- 点击“定位未保存”只显示有未保存修改的站点；点击“取消定位（显示全部）”清除筛选并返回全部站点。
- “清除数据”按钮清空该站点的 `min`、`max`、`avg` 输入，并标记为未保存；需要再点击“保存此站”才会写入工作簿。
- 点击 ID 后，菜单顺序为“查看站点信息”、“修改站点信息”、“移动站点”、“在此 ID 后插入”。“移动站点”会锁定其他操作；点击目标 ID，再选“将站点移动到此 ID 上方”完成移动，按 `Esc` 取消。移动会同时调整工作簿行顺序和 ID，使 ID 继续从 1 连续递增。例如把 ID 3 移到 ID 6 上方后，原 ID 4、5 会变成 ID 3、4，原 ID 3 会变成 ID 5。移动前需先保存或恢复未保存的数据修改。插入表单会预填所选站点除 ID 外各列的当前值；修改表单会预填所有列，ID 保持不变。插入或修改表单中，在 `latitude` 输入框粘贴制表符分隔的纬度和经度，可同时填入 `latitude`、`longitude`。查看会以只读表格显示所有列；纬度和经度共用一行，值以制表符分隔，双击该值可整段选中并复制。插入新站时，新 ID 为该行 ID 加 1，后续站点 ID 依次加 1；网页会重新按工作簿顺序显示。国家列位于保存列之后。
- 空白数据会保存为空单元格；非空数据必须是数字。
- 编辑期间请关闭 Excel 中的该工作簿，避免 Excel 和编辑器同时写入。

日常站点行保存只修改 `min`、`max`、`avg` 三列。插入新站时会在主工作表增加一行并顺延后续 ID，不会排序或重排现有站点。

载入工作簿时会检查 `latitude`、`longitude`、`elev`、`timezone` 列的非空值是否为有效数字；发现无效值时会在页面提示行号、列名和值，但不会阻止载入，可之后通过“修改站点信息”逐项修正。空白单元格允许保留。
