# 蒙古实况互动地图高度调整

Chrome Manifest V3 扩展，适用于 `https://*.weather.gov.mn/observation/weather`。

安装时打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，然后选中本文件夹。面板默认隐藏；在受支持的蒙古天气实况页面点击浏览器工具栏中的扩展图标即可显示或隐藏面板。点击“地图高度增加 100% 并收起页眉”按钮可将互动地图高度增加 100%（变为原来的 2 倍），并收起占据顶部空间的页面横幅；再次点击可恢复地图和页眉。拖动面板背景或状态文字可移动面板。点击面板右上角的 × 可关闭面板；之后仍可点击扩展图标重新打开。
