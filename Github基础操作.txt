新建Repository

********************2.********************
本地：
对应git服务器某个Repository，在本地文件夹右键Git Bash Here

初始化本地文件夹作为git仓库
git init

连通git Repository和本地仓库
git remote add origin [SSH Code]

用git Repository覆盖(更新)本地仓库(只适用于本地初次建立git仓库的情况)
git pull origin master

*
用本地仓库覆盖(更新)git Repository
git add .
git commit -m "some comments"
git push origin master

*
从本地git仓库德最近一次push恢复文件(无需联网)
git restore "目标文件名及后缀"

*
用github远程覆盖本地某个文件：
在该文件所在目录下执行git，依次执行以下2个命令(主分支是master就master，主分支是main就把master替换成main):
git fetch origin master
git restore --source=origin/master "目标文件名及后缀"

*
从本地git仓库德最近一次push恢复目标目录下的全部文件(慎用！对新添加的还未被追踪的文件不受影响，虽然方便但还是慎用！)
git restore .

*
查询最顶层git目录
git rev-parse --show-toplevel
